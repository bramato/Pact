# Security policy

PACT v0.2.0 is a draft specification with independent SDKs and a local authenticated reference service. There is no supported production deployment in this repository. Maintainers review reports against the current draft; no response-time guarantee has been established.

Report vulnerabilities privately using GitHub's **Report a vulnerability** feature when enabled, or a private contact method listed by a repository maintainer. Include the affected file/version, reproduction steps, expected boundary, and impact. Do not publish credentials, private artifacts, or exploitable tenant data in an issue. If no private channel is available, open an issue requesting one without disclosing the exploit.

Both SDKs resolve schemas from an explicit local URI-to-file registry, check exact digests, bound size and reject external references. They never fetch arbitrary schema or artifact URLs. The reference adapter authenticates server-configured local principals, scopes tasks/receipts by tenant, commits SQLite acceptance/outbox atomically and bounds delivery retries. Random local tokens and databases stay in ignored `storage/` outside the `public/` document root. JSON objects with duplicate members are rejected. Production adapters must implement HTTPS, peer authentication, server-side tenant/delegation checks, constrained schema resolution, SSRF protection, size and MIME limits, durable atomic idempotency, retention, and bounded retries. JSON Schema validates structure, not the truth or safety of agent outputs.
