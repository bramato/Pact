# Changelog

## 0.2.2 — 2026-11-18

- Share the PACT editorial connection theme across master initiation, client consent, team selection and agent status pages, with accessible controls and reusable integration guidelines.
- Allow host applications to protect inline connection styles with a per-response CSP nonce.

## 0.2.1 — 2026-11-17

- Start agent linking on the master with only a domain, automatic discovery/public OAuth registration, remote login/consent and a team selector after returning.
- Add owned named teams while preserving existing personal federations, connections, legacy integration APIs and credentials.
- Complete both credential directions with confirmed activation, encrypted temporary link state, tenant-aware identity binding, idempotent selection and revocation.
- Pin public peer DNS addresses, reject private destinations and cross-origin discovery, and test the guided flow across three isolated Laravel applications.

## 0.2.0 — 2026-11-16

First public Composer distribution of the PHP SDK and Laravel master/client package.

- Install `pact-protocol/laravel` with its `pact-protocol/core` dependency from Packagist.
- Choose a master or client role with `pact:install`; connect per-user agents through Passport authorization codes and PKCE.
- Run durable database-backed delivery, typed questions, validated artifacts and bounded Federation delegation over A2A and Laravel MCP.
- Preserve role, product identity, signing keys and pending work across repeated installation and compatible updates.
- Ship standalone packages with generated schemas, MIT license, source provenance and checksums; no Node.js build is required in consuming applications.

The protocol remains an independent draft at Core/Swarm `0.2.0`. Package versions and contract/schema versions are distinct. This release does not assert official A2A endorsement or universal production certification.

## 0.2.0 — draft, 2026-10-09

- Document portable server startup and configurable reference URLs without prerequisites tied to one developer's environment.
- Add an illustrated Italian guide covering all eleven documentation sections, an editable Word document and a coherent set of transparent chapter illustrations.
- Separate mandatory Core and optional Swarm with repository-controlled identifiers.
- Define typed event payloads and whole-envelope JCS SHA-256, exact-byte replay, concurrent atomic answers, lifecycle/output gates and bounded delivery.
- Ship independent TypeScript and PHP SDKs plus a Laravel 12 routing adapter.
- Add authenticated deterministic task/question/artifact and three-contributor HTTP demos.
- Persist acceptance, questions, task state, provenance and exact outbox bytes in SQLite; verify SIGKILL recovery and lost-response reconciliation.
- Calculate scoped weighted progress across execution, aggregation and validation, retain retry regression and a separate high watermark.
- Add shared positive/negative vectors, a live endpoint CLI, broken-peer and fault tests, standalone package smoke tests and navigable documentation.

The original supplied proposal/progress schema and v0.1 corpus remain unchanged. This is a locally implemented draft; packages and specification identifiers await owner-authorized publication.
