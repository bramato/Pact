Il problema comune era la separazione tra database persistente e chiavi su filesystem effimero. Lo stato cifrato nel database adotta l’identità e le chiavi originali. Il collaudo Laravel via HTTP rimuove i file locali dopo l’attivazione OAuth, quindi verifica il roster autenticato e il completamento di un incarico sullo stesso collegamento. I repo applicativi mantengono la responsabilità per le autorizzazioni, i worker della piattaforma e le migrazioni proprie. [Guida all’installazione Laravel](laravel-installation.md)
